# Gemini — Universal Edition v1.1

Import the native skill ZIP via Gemini > Personnaliser > Compétences > Créer > Importer. From this repository, generate the ZIP using `python gemini/build.py`. Both reference PNGs and prompts are included. No configuration required: write `COLOR — Explain how an API works` or `MINIMAL — Résume ce document`. COLOR is the default.

If the Gemini renderer cannot access a skill's image file, attach the matching PNG in chat. Actual image rendering and installation in your account have not been tested.

[Google's official Skills instructions](https://support.google.com/gemini/answer/17094296?hl=fr)
